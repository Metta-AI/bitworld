# Mortal Coil

A multiplayer social negotiation game of magic and betrayal. Players are sorcerers in a shared world, each driven by hidden passions. They cooperate to define the rules of magic itself, but compete to bend those rules in their favor. Short-term betrayal pays off — but burns the trust you need to survive.

Inspired by Brennan Taylor's tabletop RPG of the same name, adapted into a BitWorld-compatible multiplayer protocol game.

## Designer's Note

For a game to be a game, wether it's zero-sum or not, there must be the key component of **subjective interpretation**. A game only has meaning if it can be interpreted by participants, wether they're spectators or players, a fixed, programatic, set of rules is only the harness of the game, the interpretation of the outcome of such rules is what defines the game.

With that concept in mind, adversarial or cooperative behaviour only has meaning on subjective terms, to account for that:

- the players (and arbiter) of this game are LLMs each with their own context windows.
- the game's theming is generated by the players.
- the game's scenes are proposed by the arbiter.
- death exists.
- players can see what other players near them do.

## Core Concept

Players are supernatural beings sharing a single location (a seedy bar, an ancient temple, a dying city block). Each has hidden goals (passions) and limited resources (tokens). The world's magic system starts undefined — players collectively build it by spending tokens to introduce magical facts. Every fact has a price set by another player.

The social dilemma: you need other players to agree to facts that help you, but every fact you introduce gives someone else the power to set its cost. Cooperation lets everyone grow stronger. Betrayal (setting brutal prices, blocking facts, stealing resources) pays immediately but makes you a target.

## Philosophy Alignment

**Non-zero-sum:** All players benefit from a rich shared magic system. More facts mean more options for everyone. A world with many defined powers is more interesting and survivable than a barren one.

**Short-term betrayal is beneficial:** You can set crippling prices on others' magic, veto their contributions, spend power tokens to hijack scenes, or manipulate conflicts to drain opponents. These moves yield immediate advantage.

**Long-term betrayal hinders:** Players remember. A reputation for setting unfair prices means no one cooperates with your facts. Vetoing constantly gets you frozen out of alliances. The player who betrays everyone ends up with powerful but isolated magic in a world shaped against them.

## Game Structure

### Setup Phase
- 4-8 players connect and enter a shared location
- Each player privately selects 3 passions (hidden goals) from a generated set tied to the theme
- Players choose a supernatural aptitude (their magical identity)
- Magic level is set (determines total token economy)

### Play Rounds

Each round has three phases:

**1. Fact Phase (Cooperative World-Building)**
- Any player may propose a magical fact (e.g., "Vampires cannot cross running water")
- The group votes to accept or veto (threshold of credibility)
- If accepted, a *different* player sets the price (the cost of using that magic)
- Facts are permanent and shape what everyone can do
- Proposing costs a magic token (sacrifice)

**2. Conflict Phase (Competitive Token Bidding)**
- Players declare goals and pair off into conflicts
- Blind simultaneous bidding with action tokens
- Passions grant bonuses when relevant — but calling on the same passion repeatedly makes it grow obsessively, narrowing your options
- Winners achieve goals; losers suffer harm (spent tokens, reduced faculties)
- Side bets and helping are possible

**3. Power Phase (Meta-Influence)**
- Players spend power tokens to: set scenes, introduce characters, add non-magical facts, bring characters into scenes
- Power tokens are awarded by peer nomination for compelling play
- This is where reputation matters — generous players get nominated more

### Victory

The game runs for a set number of rounds. At the end, each player scores based on:
- Passions fulfilled (did you achieve what your hidden goals demanded?)
- Facts contributed (how much did you shape the world?)
- Tokens remaining (resource efficiency)
- Peer nominations received (social reputation)

No single axis wins alone. A betrayer can score high on passions but low on nominations. A cooperator may have shaped the world but neglected their own goals.

## Social Dilemma Dynamics

| Action | Short-term gain | Long-term cost |
|--------|----------------|----------------|
| Set brutal price on rival's fact | Cripple their magic | They retaliate on your next fact |
| Veto a fact | Block something dangerous | Others veto yours in return |
| Go all-in on one conflict | Dominate that round | Fatigue leaves you vulnerable next round |
| Hoard magic tokens | Keep options open | World stays undeveloped, hurting everyone |
| Nominate allies for power tokens | Strengthen your coalition | They may outgrow you |
| Betray an alliance mid-conflict | Win unexpectedly | Lose future cooperation |

## Controls (BitWorld Protocol)

- D-pad: navigate menus, select targets
- A: confirm action, commit tokens, propose facts
- B: cancel, defend, veto
- Select: open passion menu, view theme document, check token pools
- Text input: name facts, write prices, declare goals

## Display (128x128)

The game renders a top-down view of the shared location with player sprites. During conflicts, the view shifts to a split-screen token allocation interface. The theme document scrolls as an overlay accessed via Select.

## Running

Start the server:

```sh
cd /Users/me/p/bitworld/mortal_coil
nim r mortal_coil.nim --address:0.0.0.0 --port:2000
```

Connect as a player in the browser:

```
http://localhost:2000/player
```

Spectate the game (global view):

```
http://localhost:2000/global
```

No bundled Mortal Coil bot is documented yet. Use `/player` in multiple
browser tabs or native clients for local testing.

The server accepts 4-8 players. Once the minimum of 4 players connect, a 10-second countdown starts. When the countdown finishes, the game begins.

## Research Questions

This game is designed to surface:
- When do players cooperate on world-building vs. hoarding tokens?
- Do stable alliances form around complementary magical aptitudes?
- How does the price-setting mechanism create or destroy trust?
- Do agents learn to retaliate proportionally or escalate?
- Does a reputation system (power token nominations) incentivize prosocial play?
- When passions conflict between players, do they negotiate or fight?
